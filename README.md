# Toti Froti Nursery

Welcome to Toti Froti Nursery – Where little dreams grow and curiosity blooms every day! This is a simple Next.js application designed as a promotional landing page for a childcare nursery facility. It provides an overview of the nursery's philosophy, programs, and contact information, aimed at parents seeking early childhood education options for children aged 6 months to 5 years.

## Description

Toti Froti Nursery is a welcoming environment focused on nurturing creativity, exploration, and emotional well-being through play-based learning. The website serves as a static promotional page highlighting the nursery's mission to be a "home away from home," with experienced educators guiding children in developing confidence, social skills, and readiness for school.

The project is built using Next.js, making it easy to develop, optimize, and deploy a modern web application.

## Features

- **Informational Sections**: Includes a welcome message, philosophy description, age-specific programs, and contact details.
- **Child-Friendly Design**: Uses whimsical language, emojis (e.g., 👶, 🎨, 📚), and a playful tone to engage visitors.
- **Programs Overview**:
  - **Tiny Tots (6 months - 2 years)**: Gentle care and sensory exploration to build trust and motor skills.
  - **Little Explorers (2 - 3 years)**: Hands-on activities fostering confidence and social interaction.
  - **Creative Minds (3 - 4 years)**: Art, music, and storytelling to spark imagination.
  - **Ready for School (4 - 5 years)**: Pre-literacy, numeracy, and independence skills for a smooth transition to kindergarten.
- **Contact Integration**: Easy access to address, phone, email, and opening hours, with a call-to-action to schedule a visit.
- **Font Optimization**: Utilizes `next/font` to load and optimize the Geist font family for better performance.

## Technologies Used

- **Next.js**: For building the React-based web application (learn more at [nextjs.org](https://nextjs.org)).
- **create-next-app**: Bootstrapped the project for quick setup.
- **next/font**: Automatic optimization and loading of custom fonts like Geist (from Vercel).
- **Deployment**: Hosted on Vercel for seamless deployment.

## Installation

To get started with the project locally:

1. Clone the repository:
   ```
   git clone https://github.com/ahmedwagd/toti-nursery.git
   ```
2. Navigate to the project directory:
   ```
   cd toti-nursery
   ```
3. Install dependencies:
   ```
   npm install
   # or
   yarn install
   # or
   pnpm install
   # or
   bun install
   ```
4. Run the development server:
   ```
   npm run dev
   # or
   yarn dev
   # or
   pnpm dev
   # or
   bun dev
   ```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

## Usage

- Edit the main page by modifying `app/page.tsx`. The page will auto-update in the browser as you make changes.
- The application is static and informational, with no backend or interactive forms required for basic viewing.

## Folder Structure
